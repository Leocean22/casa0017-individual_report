# Individual Personal Reflection

## 1. My Contribution

My main responsibility in this project was front-end development and the overall user interface design of Find a Place. I designed the structure and layout of the single-page website, including the arrangement of the map, input panel and search controls. I also developed the HTML structure and CSS styling, making decisions about the colour scheme, typography and responsive layout. I also came up with the idea of displaying a short slogan on the right-hand side of the map before a search begins. Since we designed the website as a single-page application, this made effective use of the available space when the map was not yet displaying any results. The slogan disappears once users start searching, allowing the map to focus entirely on presenting the results.

I completed most of the front-end JavaScript development, including postcode inputs, search interactions and the integration of the Leaflet mapping library. I also worked on displaying venues and routes and connecting the front end with the back-end services. Anthony contributed to some interactive features, particularly the travel-time display, while Monong provided useful suggestions, including enlarging venue icons on the map to make them easier to identify.

I was also responsible for testing and debugging the front end, fixing various small bugs during development. In addition, I independently completed the deployment of the website to the Raspberry Pi, making the application accessible through the local network. For the group report, I wrote Sections 3 and 4, covering Design and User Experience, and Interactivity and Visualisation. I also contributed to the README, including the general project introduction and technical diagrams.

## 3. Personal Reflection and Teamwork

This project taught me that developing a complete website involves much more than writing code. It requires planning, communication and coordination between front-end and back-end development. Although our group sometimes had different opinions and discussions, I realised that clear direction and leadership are important for keeping a project organised. Being able to explain ideas logically and persuade others through reasonable arguments is equally valuable.

Technically, I gained experience in the complete website development and deployment process, API integration and Raspberry Pi deployment. We also encountered external APIs with relatively slow response times, which highlighted the value of using a local database to improve efficiency. In future, I would like to explore more advanced algorithms to improve how meeting locations are evaluated. I also learned the importance of writing readable code, adding useful comments and holding regular meetings so that everyone can understand each other's work. Overall, I believe all members contributed positively to the project, and I would give each of my three teammates 10/10.
