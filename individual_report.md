# Individual Personal Reflection

## 1. My Contribution

My main responsibility was front-end development and the user interface design of Find a Place. I designed the single-page layout, including the map, input panel and search controls, and developed the HTML and CSS. I also suggested displaying a short slogan on the right-hand side of the map before a search begins. This used the otherwise empty space, and the slogan disappears when users start searching so the map can focus on the results.

I completed most of the front-end JavaScript, including postcode inputs, search interactions and integration of the Leaflet mapping library. Anthony contributed to some interactive features, particularly the travel-time display, while Monong suggested enlarging venue icons to make them easier to identify.

I tested and debugged the front end, fixing small issues during development. I also independently deployed the website to the Raspberry Pi, making it accessible through the local network. For the group report, I wrote Sections 3 and 4, covering Design and User Experience, and Interactivity and Visualisation. I also contributed the general project introduction and technical diagrams to the README.

## 3. Personal Reflection and Teamwork

This project taught me that developing a complete website involves more than writing code. It requires planning, communication and coordination between front-end and back-end development. At first, our work was sometimes scattered because we had not agreed on a clear direction. Once we established a shared plan, we worked together more effectively. I realised that clear direction, regular meetings and logical discussion help keep a group project organised.

Technically, I gained experience in website development, API integration and Raspberry Pi deployment. Slow responses from some external APIs showed me the value of storing venue data in a local database. In future, I would like to explore more advanced algorithms for evaluating meeting locations. I also learned the importance of readable code and useful comments, so team members can understand each other's work. Overall, I believe all members contributed positively, and I would give each of my three teammates 10/10.
